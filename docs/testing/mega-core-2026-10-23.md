# First ordinary Mega route (#784–#787)

Native Venusaur holding its actual reusable Venusaurite can reserve `+mega`,
choose a legal `+attack`, become Venusaur-Mega and retain battle state through
reconstruction and cleanup. The [player guide](../mega-evolution.md) describes
the route; the [JSON receipt](mega-core-2026-10-23.json) preserves 269 exact
command/effect observations using verified lossless per-case state deltas.

## Player and transaction acceptance

An explicitly configured optional finite Counter is reached through its real
Exit command and persisted movement (ancillary move hooks disabled in this
isolated transport). Ordinary `+store` purchase debits 10,000, stock and bag;
`+inventory` observes it, the normal held-item menu equips it, and `+mega` /
`+attack` / checkpoint reconstruction / battle end / held-item return preserve
the single copy. Disabled shop, funds, stock, duplicate source and wrong holder
controls reject. This recipe has not been installed in a running world.

Fresh owned SQL provenance and canonical party/current-Fusion placement guard
the active human actor in WILD/TRAINER/PVP singles/doubles. All four doubles
labels and independent opposing sides work; allies share one side budget.
Wrong/foreign/inactive/egg/box, nickname spoofing, Transform, raw pending flags,
source contradictions, spent side, Tera conflict and no-overwrite reject.
Identical reservations are idempotent. Invalid input preserves a reservation;
cancel or legal switch/item/flee clears it without spending a use. Nested
compound reservation input rejects before mutation; ordinary standalone input
owns the transaction.

The durable turn epoch, UUID, controller, reference, slot, stone and target bind
requests across checkpoint reconstruction. Both actors' pre-Mega modified speed
and private RNG ties are captured before transformation. New form speed and
priority then govern moves, including sun/Chlorophyll loss, Trick Room and a
legally changed Prankster. A sleeping locked actor still transforms before
ordinary prevention; immunity spends the move normally. Reentry, faint/revive,
legacy dex-confirmed profiles, corrupted state, owner/item changes and same/new
battle budgets are covered. Fresh SQL source contradictions abort the whole
turn rather than resurrecting a transferred stone.

Stats use `get_stats`/`get_max_hp`, effective level, Hyper Training and configured
Fusion scale. HP, status, PP, stages, genetics, SQL species/ability/nickname and
held ownership survive. Real Fire/Ice hits prove executable Thick Fat, reduced
physical/special damage, suppression, Mold Breaker, Ability Shield and unrelated
type controls. Matching item suppression never consumes the reusable stone.
Handlers bind once; reconstruction does not replay activation. Post-activation,
checkpoint, reservation and end-sync faults restore state, actions, PP, budgets,
messages and RNG. Cleanup is repeatable and preserves native data and source.
