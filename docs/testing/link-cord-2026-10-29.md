invalidating its expectation of a switch. Production damage handling correctly
requires a surviving holder that crosses half HP; that behavior is unchanged.

authored move power to 60, and asserts `0 < HP <= max_HP // 2` before checking
the switch request. A separate deterministic Explosion case verifies that a
knocked-out holder does not queue a switch. Neither case changes global RNG
