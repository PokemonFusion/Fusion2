## What passed

- Ordinary finite Buy → bag → `+hold` → discovery → exact source/actor/target
  `+zmove` → full turn → independent SQL PP/side use → checkpoint/rebuild → end
  → return of one reusable crystal. Actual Counter entrance/return exit commands
  save the real disposable character's new location. Counter has 34 explicit
  offers at 10,000, stock 1/no refill; no source is installed in a running world.
- All eight selected status sources: bonus before base effect, useful/no-effect/
  prevention/protected-base controls, capped boosts on opposite doubles actors,
  HP healing, current-type Curse after real faster Soak, normal restrictions,
  Magic Bounce without another Z bonus or extra reflected ally, real redirection,
  one-time slot-bound replacement heal and auto-faint replacement. Replacement
  status stays unchanged; selected Tailwind's remaining timer survives reconnect
  and expires normally. Both Focus Energy and the cap signature use actual 50%
  critical probability controls, not guaranteed criticals.
- All 16 signatures have exact reviewed descriptors and active/Protect/sleep
  controls; every damaging signature has real type/ability immunity controls.
  Wrong nicknamed natives reject before queuing. Actual HP/status/stages show
  no source trapping, recoil, recharge, defensive-stage bypass, burn cure or boost
  theft. Soulblaze resolves each foe separately and grants one five-stat boost
  after any real hit; both-immune, Protect, sound/Substitute and Sheer Force
  power-without-boost controls pass. Guardian odd/low HP and protected rounding
  are exercised through the real damage consumer. Terrain effects require real
  HP/substitute damage and survive rebuild; post-terrain faults restore damage,
  field, source PP, use, RNG, input and success output before one valid retry.
- Seven exact cap forms and intact Mimikyu-Totem/Kommo-o-Totem: configured
  `+hunt` → ordinary `+item Master Ball` → `+teach` → real moveset menu → held
  signature Z use. Chart/stock/native preparation is separate fixture setup.
  Both real native Disguise breaks preserve nickname through switching,
  re-entry and rebuild as the matching Busted form, use Mimikium and leave the
  owned native species intact. Direct
  Busted grants, copied proof, Transform and unlisted World Cap cannot qualify.
- Prior whole-turn prevention, one-PP-even-Pressure, type conversion, independent
  side budgets, Mega/Tera conflicts, current Fusion, owner/source/placement guards,
  stale/invalid/no-overwrite input, rollback/retry and whole-roster ending remain
  passing. Paid last-move history preserves source PP for actual Spite after
  rebuild; explicit older references need matching activated proof, absent old
  history stays absent, and conflicting/orphan references fail closed.
- Existing medicine/berries/food, capture PP, progression, Hyper Training,
  shop/contention, growing, UI, Mega and Tera regressions pass. Plot-only content

## Remaining limits and release boundary

Other ordinary/status source moves remain explicitly deferred. Fused Necrozma
requires the separately scoped native lifecycle review [#820](https://github.com/PokemonFusion/Fusion2/issues/820);
native Lunala/Solgaleo are accepted independently. Ultra Burst/Ultranecrozium,
AI Z use and new formats remain outside the original batches. This is bounded
acceptance, not an all-move or all-native catalog claim.

This is automated local ordinary command/menu/full-turn/SQL acceptance with
captured transport and real exit traversal, separate from fresh live socket
acceptance, hosted CI, main merge or deployment. Live authored charts and stock
are unverified. No PF2-Dev source update, migration, service operation, live stock
installation or existing human-character/Pokémon change occurred. All disposable
schemas and public tables are empty; the task-owned cluster is stopped at task
closeout. Historical released-build receipts remain unchanged.
