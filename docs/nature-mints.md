# Nature mints

Use `+use Adamant Mint=3`, replacing the mint name and current party slot.
An exact owned name/full ID or your current `fusion` also works. These are
field items; move/stat selectors, eggs, boxed or foreign targets, inactive
Fusion sources and use during battle reject without spending a copy.

Mints change **mint stat preference**, stored separately from **genetic Nature**.
The twenty nonneutral preferences apply the existing named Nature's +10%/−10%
non-HP modifiers. Serious is neutral. Matching existing modifiers have no
effect and consume nothing, including Serious on any neutral genetic Nature.
HP keeps its absolute deficit; a fainted Pokémon remains at zero and a conscious
one remains alive. Stat displays and later battles rebuild the same saved
preference. Hyper Training remains a separate IV overlay.

| Group | Mint names |
| --- | --- |
| Attack and neutral | Lonely, Adamant, Naughty, Brave, Serious |
| Defense | Bold, Impish, Lax, Relaxed |
| Special Attack | Modest, Mild, Rash, Quiet |
| Special Defense | Calm, Gentle, Careful, Sassy |
| Speed | Timid, Hasty, Jolly, Naive |

There are 21 mints. Hardy, Docile, Bashful and Quirky Mint are absent. Mint
Berry remains a separate sleep-curing berry.

Breeding/Everstone, flavor-berry confusion and nature-based evolution such as
Toxtricity still use genetic Nature. Mint use preserves species, genetic Nature,
IVs, EVs, ability, progression, friendship, status, held item, moves and PP.
An active native Necrozma host may train through the shared field route; its
combined companion remains frozen. Separation preserves each source's values.
Trade/market reviews label both values separately, bind them to consent and
retain them after transfer.

One useful use commits the preference, HP refresh and one bag debit together.
Stale saved targets and invalid genetic/trained state refuse visibly. Duplicate
uses cannot spend the final copy twice. Untrained legacy rows retain their
existing genetic modifiers. Old blank genetics retain neutral compatibility
for untrained stat reads only; a mint cannot repair or hide that blank value.

The optional `world/nature_mint_counter.json` offers one finite copy of each
mint for 20,000 through `mints`/`back`, buy-only. These are PF2 prices. Code
publication installs no source and refills nothing. New schema 0059, isolated
migration rehearsals, optional world installation and deliberately released
socket acceptance require their applicable operational approvals and evidence.
See [the design contract](design/nature-mints.md) and
[the isolated rehearsal plan](testing/nature-mint-migration-plan-2026-10-25.md).
